# Founder Validation Program

Status: established August 2026; **Founder Validation Cycle 001
open** — validating the first complete end-to-end publication
performed through Huerta Group Publishing.

Lived evidence from real use of the platform, recorded durably:
observations are classified evidence about the institution — never
institutional law by assertion. The Operational Standard governs
everything in this directory.

## Records

| Record | File | Discipline |
| --- | --- | --- |
| Operational Standard | [founder-validation-program.md](founder-validation-program.md) | Amended, never silently rewritten |
| Founder Validation Register | [observation-register.md](observation-register.md) | Append-only; one line per observation |
| Validation Theme Register | [theme-register.md](theme-register.md) | Append-only; one line per theme |
| Validation Decision History | [decision-history.md](decision-history.md) | Append-only, dated entries |
| Observation template | [templates/observation.md](templates/observation.md) | Copy per observation into `observations/` |
| Theme template | [templates/validation-theme.md](templates/validation-theme.md) | Copy per theme into `themes/` |
| Decision template | [templates/validation-decision.md](templates/validation-decision.md) | Entries in the Decision History |

## Identifiers

- Observations: `FVO-<cycle>-<seq>` (cycle-scoped, e.g. `FVO-001-004`)
- Themes: `FVT-<seq>` (program-scoped — themes outlive cycles)
- Decisions: `FVD-<seq>` (program-scoped)

Sequences are monotone, assigned at recording, never reused.
